# 롤 탑 밴픽 추천 웹앱 - 전체 챔피언 버전

## 이번 버전 변경
- Next.js 16.2.6으로 업데이트
- 밴픽/우리편/상대편 선택창에서 롤 전체 챔피언 선택 가능
- 챔피언 목록은 Riot Data Dragon ko_KR champion.json에서 불러옴
- 추천 결과는 탑 후보 챔피언만 표시
- 밴/이미 선택된 챔피언은 빨간색 + 선택 불가
- 상대 조합, 우리 조합, 상대 탑 후보 카운터, 내 챔피언 풀을 합산해서 추천
- 점멸 타이머 유지

## GitHub/Vercel
압축을 풀고 파일 전체를 GitHub 저장소에 업로드한 뒤 Vercel에서 Deploy.
